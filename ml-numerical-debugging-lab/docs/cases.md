# Case studies

Generated by `python -m lab.report`. Each case shows the buggy and fixed output for the same input.

## C01: Softmax overflow

* **Symptom:** Probabilities are NaN for large logits.
* **Root cause:** exp(1000) overflows to inf; inf/inf = NaN.
* **Fix:** Subtract the maximum logit before exponentiating (mathematically identical).
* **Property checked:** Output is finite and sums to 1; softmax([1000,1001,1002]) = [0.0900, 0.2447, 0.6652].
* **Buggy output:** `[nan, nan, nan]`
* **Fixed output:** `[0.09  , 0.2447, 0.6652]`
* **Bug reproduced and fix verified:** yes

## C02: Cross-entropy of a zero probability

* **Symptom:** Loss is inf (or the training loss jumps to inf) for a confidently wrong prediction.
* **Root cause:** The probability underflows to 0.0 and log(0) = -inf.
* **Fix:** Compute the loss from logits with log-sum-exp; never take log of a probability.
* **Property checked:** Loss for logits [1000, 0] and true class 1 is exactly 1000.
* **Buggy output:** `inf`
* **Fixed output:** `1000`
* **Bug reproduced and fix verified:** yes

## C03: Standardisation on the wrong axis

* **Symptom:** Features are not zero-mean; model quality silently drops.
* **Root cause:** axis=1 normalises each sample across its features instead of each feature across samples.
* **Fix:** Use axis=0 for (samples, features) data.
* **Property checked:** Every feature (column) has mean 0 and std 1.
* **Buggy output:** `[-0.8103, -0.5982,  1.4084]`
* **Fixed output:** `[0., 0., 0.]`
* **Bug reproduced and fix verified:** yes

## C04: Train/test leakage through scaling

* **Symptom:** Validation looks better than production; changing the test set changes the training features.
* **Root cause:** Scaler statistics were computed on train + test together.
* **Fix:** Fit the scaler on the training split only and reuse it for the test split.
* **Property checked:** The transformed training data must not depend on the test data.
* **Buggy output:** `1.01876`
* **Fixed output:** `0`
* **Bug reproduced and fix verified:** yes

## C05: Low-precision accumulation

* **Symptom:** Summing 10,000 values of 0.1 returns 256 instead of ~1000.
* **Root cause:** float16 has 11 significant bits; once the sum reaches 256, adding 0.1 is below half the spacing and rounds away.
* **Fix:** Accumulate in float32 (or higher), cast at the end if needed.
* **Property checked:** The sum is within 0.5% of 1000.
* **Buggy output:** `256`
* **Fixed output:** `999.903`
* **Bug reproduced and fix verified:** yes

## C06: Catastrophic cancellation in variance

* **Symptom:** Variance of data near 1e9 comes out as 256 (true value 0.02) or negative.
* **Root cause:** E[x^2] - E[x]^2 subtracts two nearly equal ~1e18 numbers, losing all significant digits.
* **Fix:** Use the two-pass formula (or Welford's algorithm).
* **Property checked:** Variance of 1e9 + [0.1..0.5] equals 0.02 to 6 significant digits.
* **Buggy output:** `256`
* **Fixed output:** `0.02`
* **Bug reproduced and fix verified:** yes

## C07: Softplus / logistic loss overflow

* **Symptom:** log(1 + exp(x)) returns inf for x = 1000 (true value is 1000).
* **Root cause:** exp(x) overflows before the log can compress it.
* **Fix:** Use logaddexp(0, x), which is stable.
* **Property checked:** softplus(1000) = 1000.
* **Buggy output:** `inf`
* **Fixed output:** `1000`
* **Bug reproduced and fix verified:** yes

## C08: Silent broadcasting in a loss

* **Symptom:** MSE of perfect predictions is not 0; no error is raised.
* **Root cause:** pred (N,1) minus target (N,) broadcasts to an (N,N) matrix.
* **Fix:** Validate shapes explicitly and fail loudly.
* **Property checked:** Perfect predictions give 0; a shape mismatch raises an error instead of returning a number.
* **Buggy output:** `1.33333`
* **Fixed output:** `ValueError`
* **Bug reproduced and fix verified:** yes
