# Applied biomedical ML: WDBC malignancy classification

A small, fully reproducible supervised-learning project on a **verified public
biomedical dataset**: the Breast Cancer Wisconsin (Diagnostic) dataset (WDBC),
UCI ML Repository ID 17, DOI [10.24432/C5DW2B](https://doi.org/10.24432/C5DW2B),
licensed **CC BY 4.0**.

> **Status:** self-directed portfolio project by Yazan Aljabari. It demonstrates
> disciplined applied-ML practice on an open research dataset. It is **not a
> clinical device**, has not been externally validated, and must not be used for
> diagnosis or treatment decisions.

## What is here

| Path | Purpose |
|---|---|
| `data/wdbc.data` | Unmodified raw UCI CSV, 569 rows, committed with SHA-256 `d606af41…5f4a` |
| `bio_ml/data.py` | Strict loader (shape, labels, unique IDs, finite values, checksum) and stratified split |
| `bio_ml/model.py` | Train-only `Standardizer` and L2 logistic regression written from scratch in NumPy |
| `bio_ml/metrics.py` | Confusion matrix, sensitivity, specificity, PPV, NPV, F1, AUROC, Wilson intervals |
| `bio_ml/train.py` | End-to-end run; writes `reports/metrics.json` and `reports/report.md` |
| `tests/` | Dataset integrity, leakage, stability, metric and end-to-end tests |
| `docs/DATASET.md` | Provenance, license, citation, checksum, re-download instructions |

## Run

```bash
cd applied-biomedical-ml
pip install -r requirements.txt
python -m pytest -q
python -m bio_ml.train --output reports
```

## Leakage control — what is and is not claimed

Implemented and tested:

- The `Standardizer` is fitted on the **training split only**; the test split is
  transformed with those training statistics. A test mutates the test rows and
  verifies the fitted mean/scale do not move.
- Hyperparameters were fixed **a priori** (`lr=0.5`, `4000` full-batch
  iterations, `l2=1e-3`, threshold `0.5`) and were not tuned on the test set.
- The split is deterministic and stratified; train and test indices are
  disjoint by construction and asserted in tests.
- The raw file is checksum-verified before training, so an altered or partial
  download fails loudly instead of silently changing the results.

**Not** claimed:

- WDBC contains **no patient identifier**; UCI documents one fine-needle
  aspirate per mass. Patient-level (group) leakage therefore cannot be
  constructed or measured from this file, and none is claimed. See
  [`docs/DATASET.md`](docs/DATASET.md).
- No external or temporal validation exists, and 113 test samples is a small
  test set — the Wilson interval reflects that.
- Coefficients are reported as associations, not causal or clinical evidence.

## Design notes

- The model is deliberately simple and interpretable: a linear decision
  boundary on 30 standardised nuclear features. The point is the pipeline
  discipline, not squeezing the last point of accuracy.
- `_sigmoid` and the log-loss use the numerically stable forms
  (`1/(1+exp(-z))` split by sign, `logaddexp`), so extreme logits do not
  overflow.
- A constant feature maps to zero instead of dividing by zero.
- `reports/*.json`/`*.md` are written to a temporary file and moved into place,
  so an interrupted run cannot leave a truncated report.
