# Reproducibility

## Commands

Run each from a fresh shell; every command is relative to the repository root.

```bash
cd ml-numpy-from-scratch && python -m pytest -q && python scripts/train_spiral.py
cd ../ml-numerical-debugging-lab && python -m pytest -q && python -m lab.report
cd ../ml-inference-benchmark && python -m pytest -q && python -m infbench.run --batch 64 --repeats 5
cd ../ml-pytorch-training && python -m pip install -r requirements.txt -r requirements-serving.txt && python -m pytest -q && python -m pytorch_lab.train --output reports && python -m pytorch_lab.export_onnx --checkpoint reports/checkpoint.pt && python -m pytorch_lab.benchmark_cpu --checkpoint reports/checkpoint.pt
cd ../coding-agent-benchmark && python -m pytest -q && python -m bench.run
cd ../applied-biomedical-ml && python -m pytest -q && python -m bio_ml.train --output reports
cd .. && python -m pytest experiments/tests -q && python experiments/experiment_runner.py --config experiments/configs/spiral_numpy.json
```

## Verification

Local results from the final verification run (Python 3.14.7, NumPy 2.5.4,
Windows 11):

| Suite | Tests passed |
|---|---:|
| `ml-numpy-from-scratch` | 33 |
| `ml-numerical-debugging-lab` | 11 |
| `ml-inference-benchmark` | 11 |
| `ml-pytorch-training` | 8 |
| `coding-agent-benchmark` | 3 |
| `applied-biomedical-ml` | 18 |
| `experiments` | 12 |
| **Total** | **96** |

- No test was skipped, failed or errored in that run. The PyTorch suite was not
  skipped because `torch` and `onnxruntime` were installed.
- These numbers are from **Python 3.14.7 only**. CI targets Python 3.11, 3.12 and
  3.13; no feature-branch CI run exists yet, so cross-version execution is not
  verified.
- Deterministic training is verified by tests in
  `ml-numpy-from-scratch`, `ml-pytorch-training`, `applied-biomedical-ml` and
  `experiments`. Re-running a seeded command reproduces the committed metrics.
- Benchmark results are generated by execution and committed as JSON and
  Markdown, including median, standard deviation, minimum and maximum across
  repeats and the machine environment.
- ONNX logits are compared against PyTorch from the same checkpoint; the maximum
  difference is recorded in `ml-pytorch-training/reports/onnx_check.json`.
- The WDBC raw file is checksum-verified before training, so a modified copy
  fails loudly rather than silently changing results.
- No API keys or GPU are required for the default workflows.

## Environment notes

- Absolute latency values are machine-specific. Re-run the benchmark on your
  own hardware; the committed report records the machine it came from.
- Report writers use a temporary file plus an atomic replace, so an interrupted
  run cannot leave a truncated report.
- The WDBC dataset is CC BY 4.0. See
  `applied-biomedical-ml/docs/DATASET.md` for provenance and citation.
